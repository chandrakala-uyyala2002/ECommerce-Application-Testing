# Checkout Testing

## Objective
To verify that users can complete the checkout process successfully.

## Test Cases

| TC ID | Test Scenario | Expected Result |
|---|---|---|
| TC01 | Click the Checkout button | Checkout page displayed |
| TC02 | Enter valid delivery address | Address accepted |
| TC03 | Submit empty address fields | Validation message displayed |
| TC04 | Enter invalid postal code | Error message displayed |
| TC05 | Select a delivery method | Delivery method selected |
| TC06 | Check order summary | Correct products and prices displayed |
| TC07 | Check total amount | Total amount calculated correctly |
| TC08 | Continue with valid details | User proceeds to payment |

## Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
- UI Testing
