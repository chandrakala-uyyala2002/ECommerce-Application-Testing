# Order Placement Testing

## Objective
To verify that users can place orders successfully.

## Test Cases

| TC ID | Test Scenario | Expected Result |
|---|---|---|
| TC01 | Place an order with valid details | Order placed successfully |
| TC02 | Place an order without selecting payment method | Validation message displayed |
| TC03 | Complete payment successfully | Payment successful |
| TC04 | Payment failure | Payment failure message displayed |
| TC05 | Check order confirmation | Confirmation message displayed |
| TC06 | Check order ID | Unique order ID generated |
| TC07 | Check order history | New order displayed |
| TC08 | Check order details | Correct order information displayed |

## Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
