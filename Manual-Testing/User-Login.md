# User Login Testing

## Objective
To verify that users can log in successfully.

## Test Cases

| TC ID | Test Scenario | Expected Result |
|---|---|---|
| TC01 | Login with valid username and password | Login successful |
| TC02 | Login with invalid username | Error message displayed |
| TC03 | Login with invalid password | Error message displayed |
| TC04 | Submit empty fields | Validation message displayed |
| TC05 | Enter only username | Password required message displayed |
| TC06 | Enter only password | Username required message displayed |
| TC07 | Click Forgot Password | Password recovery page displayed |
| TC08 | Logout after successful login | User logged out successfully |

## Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
