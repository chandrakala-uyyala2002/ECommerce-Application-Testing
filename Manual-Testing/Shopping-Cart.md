# Shopping Cart Testing

## Objective
To verify that the shopping cart works correctly.

## Test Cases

| TC ID | Test Scenario | Expected Result |
|---|---|---|
| TC01 | Open the shopping cart | Cart page displayed |
| TC02 | View added products | Correct products displayed |
| TC03 | Check product quantity | Correct quantity displayed |
| TC04 | Increase product quantity | Quantity updated successfully |
| TC05 | Decrease product quantity | Quantity updated successfully |
| TC06 | Remove a product | Product removed from cart |
| TC07 | Check total price | Total amount calculated correctly |
| TC08 | Open an empty cart | Empty cart message displayed |

## Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
- UI Testing
