# Product Details Testing

## Objective
To verify that product information is displayed correctly.

## Test Cases

| TC ID | Test Scenario | Expected Result |
|---|---|---|
| TC01 | Open a product | Product details displayed |
| TC02 | Check product name | Correct product name displayed |
| TC03 | Check product price | Correct price displayed |
| TC04 | Check product image | Product image displayed clearly |
| TC05 | Check product description | Product description displayed |
| TC06 | Check product availability | Stock status displayed |
| TC07 | Check product ratings | Ratings displayed correctly |
| TC08 | Click Add to Cart | Product added to cart |

## Testing Types
- Functional Testing
- Positive Testing
- UI Testing
