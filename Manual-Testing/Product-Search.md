# Product Search Testing

## Objective
To verify that users can search for products successfully.

## Test Cases

| TC ID | Test Scenario | Expected Result |
|---|---|---|
| TC01 | Search with a valid product name | Relevant products displayed |
| TC02 | Search with an invalid product name | No products found message displayed |
| TC03 | Search with an empty field | Validation message displayed |
| TC04 | Search using partial product name | Matching products displayed |
| TC05 | Search using uppercase letters | Relevant products displayed |
| TC06 | Search using lowercase letters | Relevant products displayed |
| TC07 | Search using numbers | Relevant results displayed or no results message |
| TC08 | Search with special characters | Appropriate results or validation message displayed |

## Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
- UI Testing
