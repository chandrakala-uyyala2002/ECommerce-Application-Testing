# Add to Cart Testing

## Objective
To verify that users can add products to their shopping cart.

## Test Cases

| TC ID | Test Scenario | Expected Result |
|---|---|---|
| TC01 | Add a product to cart | Product added successfully |
| TC02 | Add multiple products | All products added successfully |
| TC03 | Add the same product twice | Quantity updated correctly |
| TC04 | Add an out-of-stock product | Appropriate message displayed |
| TC05 | Check cart icon | Cart count updated |
| TC06 | Remove a product from cart | Product removed successfully |
| TC07 | Update product quantity | Cart quantity updated |
| TC08 | Add product without logging in | Appropriate login prompt displayed |

## Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
