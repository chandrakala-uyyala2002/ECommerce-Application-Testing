# User Registration Testing

## Objective
To verify that users can register successfully.

## Test Cases

| TC ID | Test Scenario | Expected Result |
|---|---|---|
| TC01 | Register with valid details | Registration successful |
| TC02 | Submit empty fields | Validation message displayed |
| TC03 | Enter invalid email | Error message displayed |
| TC04 | Enter existing email | Duplicate email warning |
| TC05 | Enter weak password | Password validation displayed |
| TC06 | Password confirmation mismatch | Error message displayed |
| TC07 | Enter valid mobile number | Number accepted |
| TC08 | Enter invalid mobile number | Validation message displayed |

## Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
